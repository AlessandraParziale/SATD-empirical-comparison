# Performance vs. Sustainability in Self-Admitted Technical Debt Detection

This is the online appendix of the paper _“Performance vs. Sustainability in Self-Admitted Technical Debt Detection: An Empirical Study”_

It includes all datasets, code, vocabularies, experimental results, and additional artifacts used in the study.


## Structure
The repository is organized into **two main folders**: 

1. 📁 **/Datasets** — This folder contains all datasets used in the experiments: original datasets and undersampled versions (including the undersampling code).
2. 📁 **/LLM, /ML, /Heuristic** - These folders contain the implementations and results for each approach evaluated in the study. 
                               Each of these folders is structured into subfolder: 
                               ├── 📁 **Binary:** Code and results for binary classification experiments
                               ├── 📁 **Multi-Class:** Code and results for multi-class classification experiments
3. 📁 **/Vocabulary** - This folder contains the vocabularies used by the heuristic approaches.
4. 📁 **/graphs_trade_off** - This folder contains the graphical analysis of the trade-off between performance and execution time.
5. 📁 **/emissions.csv** - This file contains the outputs generated by CodeCarbon, reporting all results related to sustainability and energy consumption measurements.
